# treeyears.app

The website of [Tree Years](https://treeyears.app), an iPhone game: its support page, privacy policy, imprint
and licences.

The pages are generated from the app's own repository and published from there; changes made here by hand are
replaced by the next publish.

The `wristful/` folder holds the pages of Wristful, a meditation timer by the same developer: its privacy policy,
imprint and support page. They're generated and published from Wristful's own repository (`scripts/publish-site.sh`
there); Tree Years' publish leaves the folder alone. They're served at https://treeyears.app/wristful/. GitHub Pages serves the `main` branch at https://treeyears.app.
